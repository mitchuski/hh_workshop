UNDERSTANDING_KEY.md — the access ladder (an AUDITOR, and it says so)

The harness in this repo guards translation fidelity — an adversarial, non-enumerable claim space. This file is the other thing: the understanding-as-key access ladder, which is an enumerable checklist plus a human door, i.e. an auditor (ADOPTION Step 0 upstream: what you can count, count; running the Gap on an enumerable list is the universe-builder's catalogued mistake). Naming that honestly is part of the design.

The cookie jar (graduated access to the mage)

Access deepens with the rung — host-scoped, brokered, never a raw credential in anyone's context (C8):

The steward's weekly key is separate from the ladder — every student holds it exactly once (CURRICULUM.md).

The door

The last check on every rung is human: the facilitator (and on outward acts, the First Person) confirms the checklist and turns the key. An auditor plus a door — never a self-certifying gate, which would be the exact trust the proverb warns about (C30).
